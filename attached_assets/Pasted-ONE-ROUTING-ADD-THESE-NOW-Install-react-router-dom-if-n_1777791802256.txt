TEN. VERCEL CONFIGURATION.
Create vercel.json in the project root:
json{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
This ensures React Router routes work correctly on Vercel. Without this, direct navigation to /privacy or /terms returns a 404 from Vercel rather than React.
