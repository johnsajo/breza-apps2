====================================================
BACKGROUND STATE SYSTEM
====================================================

Two distinct background states. One CSS class toggle on body.
Transition between states: 600ms ease. Smooth. Deliberate.

DEMO STATE:
Body has class "mode-demo".
Background: darkroom #0D0D0D.
Hero illustration image sits as a fixed full-viewport background layer.
z-index 0. opacity 0.15. object-fit cover. pointer-events none.
Image file: /src/assets/hero-bg.jpg
Content sits at z-index 1 above illustration.

LIVE STATE:
Body has class "mode-live".
Background: darkroom #0D0D0D pure. No illustration.
Illustration layer opacity transitions to 0 over 600ms then display none.

On app load:
Check localStorage for outsideeye_key.
If no key: add class mode-demo to body.
If key exists: add class mode-live to body.

On key save: remove mode-demo, add mode-live. Trigger 600ms fade.
On key clear: remove mode-live, add mode-demo. Trigger 600ms fade.

CSS for transition:
.bg-illustration {
  position: fixed;
  inset: 0;
  width: 100vw;
  height: 100vh;
  object-fit: cover;
  z-index: 0;
  opacity: 0.15;
  transition: opacity 600ms ease;
  pointer-events: none;
}
.mode-live .bg-illustration {
  opacity: 0;
}

====================================================
TYPEWRITER.jsx
====================================================

Props: text (string), speed (number, default 38), onComplete (function).

Types characters one by one at speed characters per second.
Uses setInterval internally. Clears on unmount.
Renders text in a span. Cursor blinks after last character until onComplete fires.
Cursor: 2px amber block. Blinks at 500ms interval.
onComplete fires after final character plus 400ms pause.

====================================================
src/lib/demoEntries.js
====================================================

Export one object DEMO_ENTRIES.
Keys match room names: critique, brief, bridge, translate, jury,
colour, wordmark, library, spark.

Each key holds an array of 5 entry sets.
Each entry set contains the field values for that room's input form
AND a matching pre-written response object that exactly matches
the JSON structure the room expects from the API.

The system types the entry fields in sequence.
User reads. User presses Enter or clicks the submit button to fire.
The matching hardcoded response renders immediately.
No API call is made in demo mode.

Regenerate button picks the next entry set in the array.
Cycles back to 0 after index 4.
Each regenerate shows different entries AND different response.

src/lib/ai.js
====================================================

Import detectProvider and getModel from detect.js.

Export async function callOutsideEye(userPrompt, systemPrompt):

  const stored = JSON.parse(localStorage.getItem('outsideeye_key') || 'null')
  If null: throw new Error('NO_KEY')

  const { provider, key } = stored
  const model = getModel(provider)

  GEMINI handler:
    endpoint: https://generativelanguage.googleapis.com/v1beta/models/${model}:generateContent?key=${key}
    body: {
      system_instruction: { parts: [{ text: systemPrompt }] },
      contents: [{ role: 'user', parts: [{ text: userPrompt }] }],
      generationConfig: { temperature: 0.8, maxOutputTokens: 1500 }
    }
    Parse: data.candidates[0].content.parts[0].text

  CLAUDE handler:
    endpoint: https://api.anthropic.com/v1/messages
    headers: {
      'x-api-key': key,
      'anthropic-version': '2023-06-01',
      'anthropic-dangerous-direct-browser-access': 'true'
    }
    body: { model, max_tokens: 1500, system: systemPrompt,
      messages: [{ role: 'user', content: userPrompt }] }
    Parse: data.content[0].text

  OPENAI-COMPATIBLE handler (openai, groq, deepseek, qwen):
    endpoints per provider as previously specified.
    headers: { 'Authorization': `Bearer ${key}` }
    body: { model, max_tokens: 1500, temperature: 0.8,
      messages: [{ role: 'system', content: systemPrompt },
      { role: 'user', content: userPrompt }] }
    Parse: data.choices[0].message.content

  Error handling:
    401 or 403: throw new Error('BAD_KEY')
    429: throw new Error('RATE_LIMIT')
    all others: throw new Error('API_ERROR')

  All responses return raw text strings.
  Each room parses as JSON.
  Every room prompt: return ONLY valid JSON, no markdown fences, no preamble.
