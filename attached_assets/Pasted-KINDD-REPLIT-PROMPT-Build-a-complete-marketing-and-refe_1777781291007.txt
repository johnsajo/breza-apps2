KINDD. REPLIT PROMPT.

Build a complete marketing and reference website called KINDD. Single-page app with smooth scroll sections. Vite + React 18 + Tailwind CSS + Framer Motion for hero animations only + Lucide React for icons.

AESTHETIC.
Background: warm cream #FAF6E8 throughout the entire site. No dark mode. No toggle.
Primary text: Midnight Navy #0F172A.
Secondary text: warm grey #6B6B5E.
Accent: Breeze #B8D4E8 for links, borders, and interactive highlights.
Interactive hover: Cerulean #007BA7.
Font: Geist Sans for all UI and body. Geist Mono for last-updated stamps, source links, and disclaimer text. Import both from Google Fonts or Vercel CDN.
No shadows that feel heavy. Soft, warm, low-contrast throughout.
No cards with sharp borders. Use soft background fills, #F0EAD6 or similar warm off-cream, to differentiate sections and clusters.
Spacing is generous. This site breathes.

NAVIGATION.
Sticky top. Blurs on scroll with backdrop-filter blur. Background becomes cream at 90 percent opacity on scroll.
Left: wordmark "kindd" in Geist Sans, medium weight, Midnight Navy.
Right: menu items. Home, Guides, How KINDD Works, About Breza + You, Contact.
Hamburger menu on mobile. Smooth open and close animation.
Prominent link in nav: "Part of Breza + You" in Breeze #B8D4E8, links to brezaplusyou.com.au.
No per-app emails. Contact links to connect@tbcworldwide.com.

RESPONSIVE RULES.
Breakpoints: 320px, 375px to 414px, 768px, 1024px, 1280px to 1440px, 1920px and above.
No horizontal scroll. No clipped content. No layout collapse.
Navigation hamburger on mobile.
All section grids stack to single column on mobile.
Hero text scales down gracefully. CTA remains full-width button on mobile.
Footer rows stack vertically on mobile. App links wrap.

INTERACTIONS.
Scroll-down arrow on hero. Disappears on scroll. Framer Motion fade out.
Go-to-top arrow fixed bottom right. Appears after hero scroll. Framer Motion fade in.
Nav blur on scroll. Backdrop filter blur, cream at 90 percent opacity.
Guide accordion open and close. Framer Motion AnimatePresence. Smooth height transition.
CTA hover states. Colour shifts as specified. No heavy transforms.
No other animations. No parallax. No scroll-triggered reveals. KINDD is calm.

WHAT NOT TO BUILD.
No login. No auth. No Supabase. No backend. No API calls. No forms except contact link which is a mailto. No chat. No comments. No user submissions. No state management library. No database. No cookies beyond localStorage for guide expand state memory.
