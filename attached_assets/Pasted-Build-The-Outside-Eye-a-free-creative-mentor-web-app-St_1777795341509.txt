Build "The Outside Eye" — a free creative mentor web app.
Static React app. No backend. No database. No server.

====================================================
TECH STACK
====================================================

React 18 + Vite + plain JavaScript. No TypeScript.
Tailwind CSS for styling.
React Router v6 for navigation.
No other dependencies except Google Fonts loaded via index.html link tags.

====================================================
VISUAL DIRECTION — READ EVERY WORD OF THIS
====================================================

The concept: The Darkroom. Truth revealed in darkness.
A serious editorial tool. Not a product. Not a dashboard. Not a SaaS app.
Think: the moment a photograph develops. Amber light. Near-black space.
Something important emerging from nothing.

This is not dark mode. This is a deliberate aesthetic identity.
Near-black canvas. Warm white type. A single amber accent that earns
every pixel it occupies. Nothing decorates. Everything communicates.

NO gradients on backgrounds.
NO glassmorphism.
NO glows or neon.
NO rounded cards that look like a mobile app.
NO stock illustration. NO hero images.
Pure typography and space.

The word "AI" must never appear in any UI copy anywhere.
Say "the Outside Eye" or "this room" instead.

====================================================
src/lib/detect.js
====================================================

Export function detectProvider(key):
  starts with "AIza"          → "gemini"
  starts with "sk-ant-"       → "claude"
  starts with "sk-proj-"      → "openai"
  starts with "sk-" (not ant) → "openai_ambiguous"
  starts with "gsk_"          → "groq"
  else                        → "unknown"

Export function getModel(provider):
  gemini   → "gemini-2.5-flash"
  claude   → "claude-haiku-4-5-20251001"
  openai   → "gpt-4o-mini"
  groq     → "llama-3.3-70b-versatile"
  deepseek → "deepseek-chat"
  qwen     → "qwen-plus"
  default  → "gemini-2.5-flash"

====================================================
src/lib/ai.js
====================================================

Import detectProvider and getModel from detect.js.

Export async function callOutsideEye(userPrompt, systemPrompt):

  const stored = JSON.parse(localStorage.getItem('outsideeye_key') || 'null')
  If null: throw new Error('NO_KEY')

  const { provider, key } = stored
  const model = getModel(provider)

  GEMINI handler:
    endpoint: https://generativelanguage.googleapis.com/v1beta/models/${model}:generateContent?key=${key}
    method: POST
    headers: { 'Content-Type': 'application/json' }
    body: {
      system_instruction: { parts: [{ text: systemPrompt }] },
      contents: [{ role: 'user', parts: [{ text: userPrompt }] }],
      generationConfig: { temperature: 0.8, maxOutputTokens: 1500 }
    }
    Parse: data.candidates[0].content.parts[0].text

  CLAUDE handler:
    endpoint: https://api.anthropic.com/v1/messages
    method: POST
    headers: {
      'Content-Type': 'application/json',
      'x-api-key': key,
      'anthropic-version': '2023-06-01',
      'anthropic-dangerous-direct-browser-access': 'true'
    }
    body: {
      model: model,
      max_tokens: 1500,
      system: systemPrompt,
      messages: [{ role: 'user', content: userPrompt }]
    }
    Parse: data.content[0].text

  OPENAI-COMPATIBLE handler (openai, groq, deepseek, qwen):
    endpoints:
      openai:   https://api.openai.com/v1/chat/completions
      groq:     https://api.groq.com/openai/v1/chat/completions
      deepseek: https://api.deepseek.com/v1/chat/completions
      qwen:     https://dashscope-intl.aliyuncs.com/compatible-mode/v1/chat/completions
    method: POST
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${key}`
    }
    body: {
      model: model,
      max_tokens: 1500,
      temperature: 0.8,
      messages: [
        { role: 'system', content: systemPrompt },
        { role: 'user', content: userPrompt }
      ]
    }
    Parse: data.choices[0].message.content

  Error handling:
    status 401 or 403: throw new Error('BAD_KEY')
    status 429: throw new Error('RATE_LIMIT')
    all others: throw new Error('API_ERROR')

  All responses return raw text strings.
  Each room parses that string as JSON.
  Prompt every room: return ONLY valid JSON, no markdown fences, no preamble.
